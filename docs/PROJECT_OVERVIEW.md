# Project overview

FalconV is a centralized business operations platform covering CRM, engineering intake, project delivery, task/issue tracking, documents, KPI and expenditure reporting, approvals, risk/CAPA, dashboards, RBAC, and audit.

The first release targets a **single organization** with multiple departments and both internal and client users. Tenant tables include `organizationId` so multi-organization support can be added later.

Phases 1–5 are implemented locally: identity, CRM, delivery, reporting/finance, executive dashboard, risks, and CAPA. Production hardening (Phase 6) is still open.
